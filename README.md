# j-notes

Converts `.j` files into `.jmd` files.  .jmd files are a plain Markdown 
that any ordinary `.md` parser can render correctly, carrying extra 
metadata baked in that a plain `.md` parser won't know about or choke on. 
j-notes are self-documenting and a human principal always linked to it.

## What this is

`.j` is raw material written by a human.  It is not 
necessarily structured at all.  Writing in something similar to a .md
file will allow parsing by the AI to be as simple as possible as the
markdown step is intentionally as vague as possible.  

#DaringFireball: Doctor J is a fan. Deadpool style.

j-notes specification allows an automated process to go from .j files 
to .md files.  It's still just Markdown to a normal tool, but annotated for 
anything that's self-aware. This is pure self-documenting code.  I was here
first.

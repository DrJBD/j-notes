# Library

Finished, delivered works, kept here in their own right — not scratch
material, not a manifest of dependencies. A shelf, not a `lib/` folder.

Each work gets an entry in the catalog below and its own file (or, if
it ever outgrows a single file — a second edition, companion
material, translations — its own folder, at which point this catalog
entry points at the folder instead).

## Catalog

- **The River** — v2.1. `the-river-v2.1.md`. One book, three
  movements: *Headwaters* / *The Delta* / *The Sea*. Full manuscript,
  currently mid-revision — not yet reviewed by a human editor, so
  treat this shelf copy as a working edition, not a final one.
